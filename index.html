利用上の注意

このサイトは公開情報をもとに独自整理した参考情報です。偏差値・内申点・大学進学率・所在地は最新情報や公式情報と異なる場合があるため、受験判断では各校公式サイトと出典元を確認してください。

公開CSVには調査メモや作業ログを含めず、学校基本情報と出典リンクに必要な最小限の列だけを収録しています。地図上の位置と距離はGSI住所検索で取得した住所代表点から計算します。座標が取得できない学校は地図と距離ソートの対象外です。

学校データ出典はCSV内の出典リンクと resources/highschool_sources_stage19.md を参照。地図データ © OpenStreetMap contributors。

学校座標の出典: GSI住所検索。郵便番号検索の出典: 「位置参照情報ダウンロードサービス」（国土交通省）を加工して作成。HeartRails Geo API を利用。
